Multi Campus University Network Simulation

This project is a university network simulation developed in Cisco Packet Tracer. It connects multiple campuses using RIP dynamic routing, Local Area Network/Wide Area Network communication, subnetting, Dynamic Host Configuration Protocol, and wireless networking.

The network includes routers, switches, Personal Computers, laptops, printers, Closed Circuit Television (CCTV) cameras, and access points to create a realistic networking environment.

Technologies Used

Cisco Packet Tracer
RIP Routing Protocol
IPv4 Addressing
Subnetting
Dynamic Host Configuration Protocol
Wireless Networking
